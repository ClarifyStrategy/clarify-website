# Clarify — V1 final para prepublicación

Esta carpeta contiene la web estática lista para probar en GitHub Pages.

## Antes del dominio
- Publicar primero en la URL temporal de GitHub Pages.
- Revisar ordenador + móvil.
- Cuando se apruebe: añadir `www.clarifystrategy.com` como Custom domain desde Settings > Pages.
- No tocar MX, SPF, DKIM ni DMARC de Google Workspace.

## Contacto
La V1 usa `mailto:system@clarifystrategy.com` para evitar backend, formularios de terceros y cookies.
